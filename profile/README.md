# Hi there 👋 We are GreenWiz 格綠智 🌲

**Smart control for a low-carbon life. 智慧控制，實現減碳生活。**

GreenWiz is a Taiwan-based energy-tech team. ePowerOS connects smart meters, solar, battery storage and EV chargers on one platform, with real-time monitoring, alerts, remote control and ESG carbon reports.

格綠智是台灣的能源科技團隊。ePowerOS 把智慧電表、太陽能、儲能和電動車充電樁接在同一個平台，提供即時監控、異常告警、遠端控制和 ESG 減碳報表。

## ⚡ ePowerOS

Our energy management system, from device to dashboard.
我們的能源管理系統，從設備到畫面一手打造。

| Feature | 功能 |
| --- | --- |
| Real-time power monitoring for every factory and circuit | 每座廠區、每條迴路的即時用電監控 |
| Solar and battery storage overview | 太陽能與儲能總覽 |
| EV charger management (OCPP) | 電動車充電樁管理（OCPP） |
| Alerts for abnormal circuits | 線路異常告警 |
| Remote control of breakers and equipment | 遠端控制斷路器與設備 |
| ESG carbon reports and dashboards | ESG 減碳報表與看板 |

## 📟 Kraken smart meter 智慧電表

Kraken shows the accurate power use of every load. It comes in 1-circuit and 4-circuit models, with a water-resistant, all-metal body for outdoor use.

Kraken 讓你看清楚每個負載的真實用電。有單迴路與四迴路兩種型號，全金屬、高防水，戶外也能裝。
